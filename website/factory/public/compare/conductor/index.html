Oya Factory vs Conductor

Both run coding agents side by side, each task in an isolated git workspace, with diffs and pull requests in the app. They differ in platform, licence and what each turn shows you.

Oya FactoryConductor
LicenceOpen source, MITNot stated on its site
PriceFreeNot stated on its site; it has a Pro plan
PlatformsmacOS, WindowsmacOS
AgentsClaude Code, Codex, Antigravity, OpenCodeClaude Code, Codex, Cursor, OpenCode
Isolated workspacesA branch and worktree per laneA worktree per workspace
Your project's checks after every turnYes, with the verdict beside the replyA Checks tab for CI and merge blockers
Rewind a turnYes, a snapshot before every turnCheckpoints
Pull requestsYes, from GitHub issues to one traceable PRYes, with drafted descriptions and merge
PhoneNoAn iOS app and remote control
Cloud workspacesNo; everything runs locallyYes

Choose Oya Factory if

  • you work on Windows as well as macOS;
  • you want the source, under MIT, and no account;
  • you want your own checks run and recorded on every turn, with any turn rewindable.

Choose Conductor if

  • you are on a Mac and want its polished interface;
  • you want to follow and merge from your iPhone;
  • you want hosted cloud workspaces.

Conductor facts are from conductor.build and its documentation, read on 23 November 2026; they change often, so check the source.
