Orca runs agents.
Oya Factory proves their work.

Running several agents in parallel worktrees is table stakes. The hard part is trusting what they wrote. Oya Factory is built around that: every turn checked, every turn reversible, every agent kept out of the others' way.

Where Oya Factory goes further

  1. 01

    Your checks run on every turn

    After each turn, Oya Factory runs your project's own checks and puts the verdict beside the reply. A turn that fails is never committed for you. Orca leaves verifying a turn to you.

  2. 02

    Any turn can be rewound

    A snapshot is taken before every turn, so a bad one is undone in a click, and the undo can be undone. No digging through git history.

  3. 03

    Two agents never share a working tree

    The daemon refuses a second writer on the same checkout, across lanes and windows, so parallel agents can't sweep up each other's half-written files.

  4. 04

    Projects configured for you

    A readiness scan, an agent team and the skills your stack needs, added and kept current automatically.

  5. 05

    Lighter on your machine

    Oya Factory uses the webview your operating system already has, with a small Rust daemon per project. Orca is built on Electron, which ships its own copy of Chromium.
